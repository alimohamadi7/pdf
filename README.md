# Persian PDF Annotator

ابزاری برای نوشتن متن فارسی، هایلایت کردن و ویرایش فایل‌های PDF با تمرکز بر پشتیبانی از زبان فارسی و متن‌های راست‌به‌چپ (RTL).

این پروژه امکان مطالعه، علامت‌گذاری و افزودن توضیحات به فایل‌های PDF را فراهم می‌کند و در پایان، یک فایل PDF جدید با تمام تغییرات اعمال‌شده تولید می‌کند.

## ✨ Features

* 📝 اضافه کردن متن فارسی به صفحات PDF
* 🖍️ هایلایت کردن بخش‌های مهم متن
* 📌 افزودن یادداشت و Annotation به صفحات
* 🌐 پشتیبانی از متن‌های راست‌به‌چپ (RTL)
* 📄 نمایش و ویرایش فایل‌های PDF
* 💾 ذخیره و اعمال دائمی تغییرات روی فایل PDF
* 📥 تولید خروجی PDF جدید با تمام تغییرات اعمال‌شده
* 🎨 مدیریت ظاهر متن‌ها، یادداشت‌ها و هایلایت‌ها

## 🎯 هدف پروژه

بسیاری از ابزارهای ویرایش PDF موجود، پشتیبانی کاملی از زبان فارسی، متن‌های راست‌به‌چپ و نیازهای کاربران فارسی‌زبان ندارند.

هدف این پروژه ایجاد یک ابزار ساده و کاربردی برای مطالعه، یادداشت‌برداری و ویرایش فایل‌های PDF فارسی است؛ به شکلی که کاربران بتوانند متن اضافه کنند، بخش‌های مهم را مشخص کنند و فایل نهایی را با تغییرات ذخیره کنند.


## 🛠️ Technologies

Technologies used in this project:

* HTML / CSS / JavaScript
* PDF Processing Library
* Canvas API
* RTL Text Support
* Browser-based PDF Rendering and Editing

## 📌 Usage

1. فایل PDF مورد نظر را باز کنید.
2. صفحه مورد نظر را انتخاب کنید.
3. متن فارسی یا یادداشت خود را به فایل اضافه کنید.
4. بخش‌های مهم را Highlight کنید.
5. تغییرات را ذخیره کنید.
6. فایل PDF جدید را با تغییرات اعمال‌شده دریافت کنید.
